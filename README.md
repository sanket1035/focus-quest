# Focus Quest

Two-player tracker for placement prep (2 Nov to 6 Dec 2026).
Full days: 3.5 hours (2 h Prep, 1 h DS/ML, 30 min English). Light days (3-4 Nov, 15-20 Nov, 23 Nov-4 Dec): English speaking 30 min only. Any missed day from 2 Nov to 6 Dec breaks the streak.

## Scoring (per day, max 135)
| Item | Points |
|---|---|
| Coding questions solved | 10 each, max 3 (30) |
| Aptitude correct | 1 each, max 30; +5 if 20+ attempted and 70%+ accuracy |
| Theory minutes | up to 15 (30 min = full) |
| English minutes | up to 20 (30 min = full) |
| Spoke only English today | +5 |
| Full day (2+ coding, 20+ aptitude, 30 min English) | +10 |
| Streak | +2 per consecutive day, max 20 |
| Missed day (no log) | -10 |

Honest logging only. Logging fake numbers just means losing on the actual test.

## Setup (10 minutes)
1. supabase.com -> New project -> SQL Editor -> run `schema.sql`.
2. Settings -> API: copy Project URL and anon key into `config.js`. Set player names.
3. Push to GitHub. Settings -> Pages -> Deploy from branch `main` / root.
4. Open `https://<user>.github.io/focus-quest/`.
